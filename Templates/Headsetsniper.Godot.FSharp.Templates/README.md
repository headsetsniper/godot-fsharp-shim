# Headsetsniper.Godot.FSharp.Templates

This package publishes the Godot F# project scaffolds that power the `godot-fsharp` `dotnet new` template. It mirrors the generator and guidance available in the main shim package.

For full documentation, tutorials, and release notes, see the Headsetsniper.Godot.FSharp.ShimGen README on NuGet:

https://www.nuget.org/packages/Headsetsniper.Godot.FSharp.ShimGen/#readme-body-tab
